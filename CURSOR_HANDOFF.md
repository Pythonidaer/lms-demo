# LMS integration handoff

This is a working static LMS generated by Design Lab. Keep learner markup and behavior from lms-runtime.js and use course.json as the course model. Sections can nest and contain slide decks, videos and multiple-choice quizzes. finalQuiz is separate. lms.css uses --lms-brand and --lms-radius; adapt those to shared website theme tokens. Course settings also store background/surface/text/muted/border colors, typography scale, spacing and content width.

The populated course now has 20 sections, 40 authored slide lessons, 60 section questions and 20 final questions. Edit scripts/build-course.py and regenerate both course.json and index.html. Runtime schema 1 now also preserves lesson sources/objectives/minutes and section studyGuide metadata; plain fenced code is escaped and rendered as pre/code. A section export unlocks only after all its children are complete, including its quiz. It includes notes and attribution. Design Lab’s original exporter may not preserve these additional fields; do not overwrite this curriculum by re-exporting an old starter model.

Run npm ci && npm test for content/type/runtime checks. UI traversal is npm run test:browser against a local static server with Playwright installed. docs/SOURCES.md distinguishes taught topics from reference-only inventory; it is not a RAG corpus. Old animation files are retained as existing assets, but are not used as instructional videos.

Test Learn, Reports, Settings, mobile outline, keyboard navigation, completion gates, retakes, captions/transcripts and browser persistence at 390/768/1440px. No video autoplays. Plain lesson text is escaped. Uploaded assets are local; external URLs stay external.

For shared reporting add users/enrollments, courses, lesson completions and quiz-attempt tables with an authenticated API. Grade on the server for trustworthy scores; never trust client completion/CSV. Add roles, access controls and a real instructor report before production multi-user use. Evaluate SCORM/xAPI only if needed by the target platform.
